# Pronto Soccorso – web app

Web app per iPhone (e PC) per controllare e reintegrare le cassette di pronto soccorso:
quantità e scadenze, controlli periodici, modulo Rev.04 compilato in PDF, elenco dei pezzi da chiedere,
date dei controlli nel Calendario.

Il codice è pubblico, i dati no: restano nel telefono di chi la usa (copia di sicurezza in un file).
